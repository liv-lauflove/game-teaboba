# 🍵 Boba & Bakery Cozy Cafe Game

A cozy, cute, feminine tea & bakery mini-game simulator built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and **Zustand**.

![Preview Aesthetic](https://raw.githubusercontent.com/liv-lauflove/game-teaboba/main/PRD.md)

## ✨ Fitur Utama
- **Aspect Ratio 9:16:** Didesain pas untuk layar mobile vertikal atau web frame estetik.
- **Racik Minuman & Foam:** 
  - *Milk Tea* dengan topping Boba kenyal.
  - *Matcha Latte* dengan pilihan foam warna-warni (*Original Milk Foam*, *Ube Purple Foam*, *Strawberry Pink Foam*).
- **Etalase Snack & Piring Mini:** Sajikan Cheesecake dan Cookies berdampingan dengan minuman di atas nampan kayu.
- **Sistem Hari (Day Progression):** Buka toko dari Day 1, kumpulkan target koin, buka resep baru, dan layani pelanggan harian.
- **Visual Clue Thought Bubble:** Pelanggan meminta pesanan lewat balon pikiran bergambar yang intuitif.
